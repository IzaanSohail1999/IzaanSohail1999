# Izaan Sohail

Senior software engineer. I design the backend and the AI feature as one system, then take it through to production.

I have been building software since 2019. Clients use me when a product needs an API that stays fast, a database that does not double-book or double-charge, and an AI answer that comes from their own documents instead of guessing.

## What I build

- Document search and assistants. The model answers from the client's files, with a check that the reply stays on those files.
- Booking and payment systems. Slots and balances are locked in the database so two users cannot take the same one.
- APIs and background jobs. Queues, retries, and logs, so a spike does not drop work.

## Stack

Python, FastAPI, Node.js, PostgreSQL, Docker, AWS.

Also Django, Flask, React, Next.js, and OpenCV when the product needs them.
